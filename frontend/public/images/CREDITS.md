# Image credits — FUD Campus Care landing page

All photographs used in the landing-page hero slideshow are genuine photographs of
Federal University Dutse (Dutse, Jigawa State, Nigeria), sourced from Wikimedia Commons.
Each file below was downloaded from its Wikimedia Commons file page and lightly
downscaled so the hero loads quickly; no other edits were made.

Wikimedia Commons files are re-used under the licence stated on each file page. For the
CC BY-SA images this requires **attribution** (given below) and, if you modify and
redistribute them, **share-alike**. The CC0 image carries no attribution requirement.

The hero renders these with `background-size: cover`, so no fixed pixel width is
required; anything at or above roughly 1280 px wide is comfortably sharp on the
wide hero band.
